# Nuxt를 활용한 뉴스 API 웹 애플리케이션 만들기

### 프로젝트 개요

안녕하세요! '구디사는 개발자 9Diin' 입니다. <br />
해당 프로젝트는 Nuxt와 컴포지션 API 그리고 Shadcn UI라는 디자인 시스템을 활용하여 간단한 뉴스 조회 웹 애플리케이션을 만들어 보는 프로젝트입니다. <br />
뉴스(News) API를 활용하여 완성도를 높여보도록 하겠습니다.

### 프로젝트 기능 소개

1. Shadcn UI를 활용하여 UI를 구성하기 (개발 시점의 Vue.js 버전에 호환 가능한)
2. 뉴스 API를 활용하여 데이터 바인딩을 진행 (초깃값은 'korea' 그리고 개발 시점의 근래 날짜를 조회 용도 데이터로 사용)
3. Pinia를 통해 중앙집중식 상태관리를 통해 필요한 상태(state) 값들을 관리
